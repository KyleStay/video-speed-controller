# StayFast Video support

## Before reporting a problem

1. Update StayFast Video and your browser.
2. Reload the affected page.
3. Confirm that StayFast Video is enabled for that site.
4. Check whether another extension changes the same media player or shortcuts.
5. Try a simple HTML5 video on another site to determine whether the issue is
   site-specific.

## Report a bug

Use the issue tracker in the public StayTech source repository. Include:

- Browser name and version
- StayFast Video version
- Operating system
- The affected page URL, when it is safe to share
- Steps that reproduce the problem
- Expected and actual behavior
- Whether the issue still occurs with other media-control extensions disabled

Do not include private page content, account details, session tokens, personal
information, or copyrighted media.

## Security reports

Do not publish a vulnerability that could put users at risk. Follow the private
security-reporting instructions in the public repository once available.

## Privacy questions

Read the [privacy policy](../PRIVACY.md). For remaining questions, use the
support channel linked from <https://staytech.co/stayfast>.

## Project lineage

For questions about attribution and the original project, see
[Open-source acknowledgments](ATTRIBUTION.md). StayTech support covers StayFast
Video only; the original project and its contributors do not provide support
for this edition.
