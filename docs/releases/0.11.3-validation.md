StayFast Video `0.11.3` is a technically validated Chrome upload candidate.
Its live [store listing](https://chromewebstore.google.com/detail/stayfast-video-speed-cont/inojpjdelhcipcommmoibfahlgkekijo)

the version decision. Unpublished dashboard drafts, account fields and vendor

- `npm run lint`: passed on the final candidate.
- `npm test`: 55 files, **707 tests passed**, zero failures. Revalidated after
  the combined dependency upgrades on the minimum supported Node.js 22.22.2.
- `node tests/e2e/run-isolated.js basic youtube fixtures-chrome`: **45 passed**
  (21 basic, 12 live YouTube, 12 Chrome fixtures), zero failures. These exercised
  the final version, UTF-8 correction and parent/iframe shortcut repair.

  optional marquee 1400×560. They remain illustrative UI compositions, as documented
  in `store-assets/chrome/README.md`.
