# StayFast Video 0.11.6 — automatic settings saves

Settings now save automatically. Typing coalesces after a short pause, while
committed changes save immediately. **Revert** undoes the latest saved edit or
discards a pending or invalid draft. Reset and import can also be reverted while
the options page remains open.

Writes, reset, import and revert run in order. Ordinary edits and their undo touch
only changed fields, preserving unrelated preferences. No permissions, network
services or runtime extension-arbitration protocol are added.
