# StayFast Video 0.11.3 — Chrome Web Store update

Upload `release/stayfast-video-chrome-0.11.3.zip` to the existing StayFast Video
item, ID `inojpjdelhcipcommmoibfahlgkekijo`. The live public listing showed
version `0.11.2`, updated October 4, when checked on October 5, 2026. Version
`0.11.3` exceeds that published version; check for any newer unpublished draft
in the dashboard before uploading.

## Release notes

- Gives Focus Peek priority for its configured zoom/pan shortcut while a usable
  preview is active. Closing the preview restores StayFast rewind immediately.
- Keeps parent and iframe shortcut actions in their own documents.
- Preserves iframe shortcuts, typing, native controls, custom bindings and
  exclusive-key behavior during shortcut cooperation.
- Fixes garbled speed-range text in the popup by declaring UTF-8 in both UI pages.
- Replaces the privacy policy's broken contact URL with the public support tracker.

No permissions or data collection are added. The complete Chrome ZIP contains
`manifest.json` at its root. Keep the existing listing and extension ID.

## Validation and upload

See `0.11.3-validation.md` for current test results and artifact hashes.
Build with `npm run lint`, `npm test`, `npm run build:release:chrome`, and
`npm run package:chrome`. Upload through **Package → Upload New Package**, verify
version **0.11.3**, review listing/privacy fields and submit for review.

No extension login or credentials are required for reviewer testing. With both
updated extensions enabled, hover an image link to open Focus Peek, press Z to
zoom and Shift+Z to pan, then close the preview and confirm Z rewinds a page
video again. Test D/S/R speed controls on a public HTML5 video as usual.
