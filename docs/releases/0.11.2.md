# StayFast Video 0.11.2 — Chrome Web Store update

Upload `release/stayfast-video-chrome-0.11.2.zip` to the **existing** StayFast
Video item. The ZIP includes the complete minified Chrome extension, with
`manifest.json` at its root. Do not upload a source archive or Firefox ZIP.
Version 0.11.2 exceeds the repository's previous v0.11.1 release tag; verify the
existing item's highest uploaded version is lower than 0.11.2 before uploading.

## Release notes

More dependable playback controls on busy pages:

- Fixes speed controls for videos loaded further down X/Twitter feeds.
- Restores controls when a site removes or moves the player overlay.
- Keeps YouTube controls and shortcuts working when navigating between videos.
- Improves multi-video and iframe handling, with independent speed-reset state
  for each video.
- Processes large page updates in smaller slices and avoids duplicate scanning.
- Improves cleanup when videos are removed or the extension is disabled.

This release adds no extension permissions or data collection. Settings remain
in browser extension storage; page media is controlled locally. The existing
single-purpose description and privacy disclosures continue to apply.

## Upload steps

1. Open the [Chrome Web Store developer dashboard](https://chrome.google.com/webstore/devconsole/).
2. Select the existing **StayFast Video: Speed Controller** item.
3. Choose **Package → Upload New Package** and select the Chrome ZIP above.
4. Verify the dashboard shows version **0.11.2**. Review any required listing,
   privacy, or distribution fields, then choose **Submit for Review**.
5. Choose automatic publication after approval, or deferred publication if you
   want to publish manually after review.

The [official update guide](https://developer.chrome.com/docs/webstore/update)
describes this flow. The existing
[submission packet](../CHROME_WEB_STORE_SUBMISSION.md) has permission
justifications and listing copy if the dashboard asks for them.

## Review testing notes

Open a public YouTube video and confirm that the StayFast overlay is visible
when the player controls are visible. Use **D** to increase speed, **S** to reduce
speed, and **R** to reset it. Click the overlay buttons, seek, and select another
recommended video without reloading the page. On X/Twitter, scroll to a newly
loaded video and confirm the same controls and shortcuts work.

No extension login, backend, or credentials are required. X/Twitter may require
its own site login to browse a personalized feed.
